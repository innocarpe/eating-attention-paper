# ADR-001: 정적 학습 사이트 프레임워크

- 상태: 승인됨
- 결정일: 2026-07-30

## 맥락 (Context)

이 프로젝트는 한국어 학습자를 우선으로 지원하면서도 다른 언어를 추가할 수 있어야 한다. 배포 결과물은 GitHub Pages에서 제공되는 정적 사이트여야 하며, 상호작용이 필요한 화면만 클라이언트 JavaScript를 내려야 한다. 콘텐츠 작성에는 MDX가 필요하고, 타입 오류는 빌드 전에 차단해야 한다.

## 결정 (Decision)

Astro를 정적 사이트 생성기로 사용하고, `strict` TypeScript를 기본 컴파일 계약으로 둔다. 학습 콘텐츠는 MDX로 작성한다. 상호작용 컴포넌트는 Preact island로만 구현하고, 페이지 전체를 클라이언트 앱으로 만들지 않는다. 문구·날짜·경로는 한국어 기본값과 로케일 키를 분리하여 i18n 확장이 가능하게 작성한다.

## 대안 (Alternatives)

- 전체 Preact SPA: 정적 우선 배포와 island 단위 JavaScript 최소화에 맞지 않아 채택하지 않는다.
- 서버 렌더링 애플리케이션: GitHub Pages의 정적 호스팅 계약을 충족하지 않아 채택하지 않는다.
- 순수 Markdown: 필요한 상호작용 컴포넌트 삽입과 콘텐츠 확장성을 제한하므로 채택하지 않는다.
- JavaScript만 사용: 컴파일 단계의 계약 검증을 약화하므로 채택하지 않는다.

## 결과 (Consequences)

새 UI는 먼저 정적 Astro/MDX로 표현하고, 브라우저 상태·입력·실행이 필요할 때만 작은 Preact island를 추가한다. 공유 타입과 콘텐츠 스키마는 strict TypeScript에서 오류 없이 표현되어야 한다. 한국어를 하드코딩한 구조적 키나 URL 설계는 금지하며, 번역 가능한 문자열은 로케일 경계에 둔다.

## 검증 (Verification)

**현재 확인된 사실**: 승인된 기술 계약은 Astro + strict TypeScript + MDX + Preact islands이며, 한국어 우선/i18n 준비 상태를 요구한다.

**릴리스 시 필요한 증거**:

1. 정적 빌드 산출물이 서버 런타임 없이 생성되는 로그.
2. TypeScript strict 검사가 통과한 로그.
3. MDX 콘텐츠와 Preact island가 실제 정적 페이지에서 렌더링되는 확인.
4. 기본 한국어 화면 및 최소 한 개의 로케일 확장 경로가 문자열/경로 분리를 유지한다는 검토 기록.

## 실패 및 출시 금지 (Failure / No-go)

정적 빌드가 서버 런타임을 요구하거나, strict 타입 검사가 실패하거나, 전체 페이지가 불필요하게 클라이언트 hydration되면 출시하지 않는다. 한국어 기본 콘텐츠가 누락되었거나 새 문자열을 번역 불가능한 구조에 넣은 경우에도 출시 금지이며, 해당 경계를 수정한 뒤 위 릴리스 증거를 다시 수집한다.
