# Capstone template — Attention Is All You Need

이 템플릿은 학습 사이트와 **별도 GitHub 저장소**로 제출하는 캡스톤용입니다.

## 제출물

1. `implementation/` — 작은 Transformer 구현과 테스트
2. `explanation.md` — 전체 구조 설명 (한국어, 영어 용어 병기)
3. `critique.md` — 논문 설계·실험·한계 비판
4. `capstone-evidence.yml` — 자기평가 점수와 증거 경로
5. `review/` — 독립 검토 기록(있을 때만 `reviewed` 주장 가능)

## 점수

각 영역(implementation / explanation / critique) 0–4점, **각각 ≥3** 필요.

## 금지

- 학습 사이트가 저장소를 fetch/자동 채점한다고 가정하지 말 것
- branch-only URL, 짧은 SHA를 immutable evidence로 제출하지 말 것
- 자기평가와 독립 검토를 같은 상태로 표시하지 말 것
